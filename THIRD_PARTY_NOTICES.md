# Third-party notices

## TerrariaModder Core UI concepts

The UI primitives in `src/TerrariaEncyclopedia.Runtime/UI` adapt selected
concepts and algorithms from the `UI` module of TerrariaModder Core v0.4.0
(commit `ab3dd67011ad2c92bbda12fc06a7354abc04d0d9`). The adapted surface is
limited to panel layout, scrolling, text input, checkbox, colour palette,
text layout and tooltip behaviour. No TerrariaInjector source is included.

Source: <https://github.com/Inidar1/terraria-modder/tree/v0.4.0/src/Core/UI>
